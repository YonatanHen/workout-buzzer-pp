# workout-buzzer-pp

Public privacy policy for the **Workout Buzzer** Android app. This repo exists only to host
`index.html` on GitHub Pages — the app source is private and lives elsewhere.

Published at <https://yonatanhen.github.io/workout-buzzer-pp/>, which is the URL given to the
Google Play Console and compiled into the app as `PRIVACY_POLICY_URL`.

## Editing

Change `index.html`, update the date at the top of the page, push. Pages redeploys on its own.

Keep it in step with the in-app copy (`src/i18n/locales/en.ts`, `privacy.*`) and with the Play
Data safety declaration — the three must agree.
